# 📊 Sales Report Dashboard (Excel)

## 📌 About Project

This is an **Excel Dashboard** created to analyze sales data of a company (**XYZ Corp.**) from **2014 to 2017**.
It helps in understanding sales performance, quantity, and profit across different categories and regions.

---

## 🔧 Tools Used

* Microsoft Excel
* Pivot Tables
* Charts & Slicers

---

## 📊 Dashboard Shows

* Total Sales (Year & Quarter wise)
* Quantity by Sub-Category
* Segment-wise Quantity
* Region-wise Profit

---

## 📈 Features

* Interactive **Slicers**:

  * Ship Mode
  * Segment
  * Region
* Dynamic filtering of data
* Bar charts and donut charts
* Year-wise and quarter-wise analysis

---

## 💡 Insights

* Some sub-categories have higher quantity sales
* Sales increase over the years (2014 → 2017)
* Different regions show different profit levels
* Corporate segment contributes significantly
